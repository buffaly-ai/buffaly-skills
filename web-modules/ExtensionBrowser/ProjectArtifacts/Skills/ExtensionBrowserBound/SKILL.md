# ExtensionBrowserBound
Package-owned actions for the ExtensionBrowser WebModule. Production actions resolve the current session's opaque binding and never accept ports, credentials, installation IDs, or session keys. Dedicated active-tab, visible-page-text, and navigation actions let natural-language requests resolve directly to safe bound capabilities instead of guessing free-form tool names. `ToGetBoundExtensionPageText` routes to the extension's `get_page_text` capability, which reads visible document text without exposing arbitrary JavaScript execution. The generic invoker is reserved for its documented supported tool names; `runScript` is not part of the bound extension protocol.
