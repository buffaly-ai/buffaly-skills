# ExtensionBrowserBound
Package-owned context and actions for the ExtensionBrowser WebModule. `ExtensionBrowserBoundSession` is the prompt context assigned to every newly created Chrome conversation; it treats the current browser context/tab as live conversational context, requires fresh browser evidence for page-dependent responses, and preserves action confirmation and prompt-injection boundaries. Production actions resolve the current session's default ExtensionBrowser instance/context and never accept ports, credentials, installation IDs, or session keys. Dedicated active-tab, visible-page-text, and navigation actions let natural-language requests resolve directly to safe session-default capabilities instead of guessing free-form tool names. `ToGetBoundExtensionPageText` routes to the extension's `get_page_text` capability, which reads visible document text without exposing arbitrary JavaScript execution. The generic invoker is reserved for its documented supported tool names; `runScript` is not part of the ExtensionBrowser protocol.
