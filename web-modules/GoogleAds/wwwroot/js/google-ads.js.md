# google-ads.js

Interactive component route state is authoritative for a launched screen. Connection-status defaults populate customer and login-customer fields only when the route omitted those values; they must not overwrite exact IDs selected by Agent inventory tools before dashboard data loads.

Campaign routes validate against the complete campaign inventory used by Agent tools, then merge date-window metrics onto those rows. A valid campaign with no activity in the selected window remains displayable with zero metrics rather than being misreported as stale.
