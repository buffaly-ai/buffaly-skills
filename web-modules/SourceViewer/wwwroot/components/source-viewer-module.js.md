# SourceViewer interactive component

Registered read-only SourceViewer component for exact file or directory targets. Files use the shared language map and bundled CodeMirror modes with line focus/highlighting. Directories render an immediate, bounded names/types-only list and send navigation to the standalone directory view; child files use generic `buffaly://file/open` routing. No recursive reads, file metadata disclosure, mutation, or reparse traversal is provided. Component lifecycle events, error rendering, and system light/dark presentation remain intact.
