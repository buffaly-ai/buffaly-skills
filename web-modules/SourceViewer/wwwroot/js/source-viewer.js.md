Loads an explicitly supplied local source target through `/api/buffaly.source-viewer/source-target`. Files retain canonical-path language detection, lazily loaded bundled CodeMirror modes, exact-text Copy, and read-only line-number rendering. HTML files show an obvious Preview button that toggles between the unchanged CodeMirror source and a separately loaded isolated rendered iframe; Copy and Close remain available in both modes. Patch/diff launches may include a same-origin `download` URL, displayed as a separate original-download action without changing editor text. Directories receive a distinct `DIR` header and bounded immediate-child list. Public entries contain only name/kind; child request paths are derived from the displayed current directory plus the selected name, then revalidated by the server. Directory navigation preserves encoded Windows paths and a fixed opened-root boundary; Up cannot leave that root. Locked reparse/inaccessible entries are disabled. Supported source files reopen SourceViewer, while other files return to generic `buffaly://file/open` routing. Close remains available and Copy is hidden for directories. ASCII title/status separators remain intentional for encoding stability.
