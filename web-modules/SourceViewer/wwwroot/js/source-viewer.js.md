# Standalone SourceViewer script

Loads an explicitly supplied local source target through `/api/buffaly.source-viewer/source-target`. Files retain canonical-path language detection, lazily loaded bundled CodeMirror modes, exact-text Copy, and read-only line-number rendering. Patch/diff launches may include a same-origin `download` URL, displayed as a separate original-download action without changing editor text. Directories receive a distinct `DIR` header and bounded immediate-child list. Directory navigation preserves encoded Windows paths and a fixed opened-root boundary; Up cannot leave that root. Reparse/inaccessible entries are disabled. Supported source files reopen SourceViewer, while other files return to generic `buffaly://file/open` routing. Close remains available and Copy is hidden for directories. ASCII title/status separators remain intentional for encoding stability.
