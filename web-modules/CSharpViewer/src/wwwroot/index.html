        What is listed here?

        Existing github.com checkouts under approved source locations on the Buffaly server, not a cloud listing. Discovery is bounded to 6 levels, 5,000 folders, 500 repositories and 2 seconds. Nothing is cloned, fetched, built or run.

          Limits

          Explorer lists files and empty folders; binary files cannot open as text. Build and dependency folders, .git and artifacts are excluded. Trees over 10,000 entries or 16 folder levels require a narrower folder. If a repository is missing, an administrator must add its source location to CSHARP_VIEWER_ROOTS.
