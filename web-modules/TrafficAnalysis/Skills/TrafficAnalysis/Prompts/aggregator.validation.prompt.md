# Aggregator Output Validator

Validate before success:
- `artifacts/traffic-summary.json` exists and `artifacts/traffic-summary-email.html` was not generated by the aggregator;
- `templateVersion` is exactly `intelligence-factory-traffic-email.v1`;
- top-level properties are `templateVersion`, `reportLabel`, `timeframe`, `headline`, `executiveSummary`, `actions`, `visualizations`, `sources`, `footer`, and exact hash-matching `promptProvenance`;
- every visualization is evidence-backed, compares meaningful numeric values, and contains `key`, `title`, `description`, `unit`, and items with `label`, numeric `value`, and formatted `displayValue`; reject decorative source-readiness/count charts;
- every expected source appears once in stable order and has `key`, `name`, `status`, `summary`, string `label`/`value` metrics, `insights`, and `diagnostic`;
- failed/missing sources contain no invented metrics and include available diagnostics;
- headline, executive summary, actions, source summaries, metrics, and insights remain presentation-neutral data values only, with no HTML, Markdown, CSS, SVG, or template markers;
- human-versus-LLM/bot analysis appears when traffic data exists;
- generation succeeds with partial inputs.

Correct failures and revalidate. Return success only with concrete artifact evidence.
