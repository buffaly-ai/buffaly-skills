# GoDaddyActions.pts

The GoDaddy skill exposes existing JSON inventory tools separately from registered read-only interactive displays. `ToViewGoDaddyDomainsInteractiveSite`, `ToViewGoDaddyDomainInteractiveSite`, and `ToViewGoDaddyDnsInteractiveSite` launch the manifest-registered `godaddy-module` through `IAgentRuntimeHost.LaunchWebModuleComponent` using serialized domain state. Exact domain routes must first be resolved with `ToListGoDaddyDomains`; stale domains fail without fallback. DNS, nameserver, settings, and transfer mutations remain separate confirmation-gated tools and are unavailable in interactive component mode.
