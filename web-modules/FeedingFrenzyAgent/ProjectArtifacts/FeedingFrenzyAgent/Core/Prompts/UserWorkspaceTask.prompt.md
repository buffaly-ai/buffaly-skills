# Maintain a Local Task
Use this session's task tools, not CRM Tasks. First list/read an existing task for the same work; do not duplicate it. Preserve the title, Status, scope, requirements, acceptance criteria, source/design references, evidence, decisions and unresolved work. Save the complete Markdown through ToSaveLocalTask, then read it back. Use root task-name.md, a title beginning #, Status: Open/Blocked/Superseded/Closed and ## Acceptance Criteria. Keep Plan short and Scratch for raw notes. Mark Closed only when acceptance is evidenced or the user explicitly ends the work; state unrun checks honestly. Use ToSetLocalTaskStatus for status-only changes. Generated deliverables belong under artifacts, never in the session root. Neither file patching nor artifact deletion is available.
