# Marketing Website Sales Skill

Website sales/demo workflows for website analysis, sales packets, proposal collateral, static demo sites, staging previews, outreach emails, and service-order sales documents.

Pharmacy sales workflows include lead enrichment, reputation and directory auditing, validated FairPath growth proposal decks, and personalized one-page direct-mail growth inserts. Their prompt, validation, frozen-template, contract, logo, and reference assets are owned by this package rather than a session artifact or Matt-local personal node.

`ToCreatePharmacyGrowthProposalDeckSkill` v3.5.0 is the single user-facing pharmacy/FairPath proposal workflow. It accepts a Feeding Frenzy LeadID or company name with optional website URL, resolves the official website when missing, internally runs or reuses the validated website opportunity audit for confirmed official websites, and skips that audit when no official site is confirmed. Its packaged `reference-packet-template/` now includes the 16-slide HTML template, `IMPLEMENTATION_NOTES.md`, `slide-content-contract.json`, shared brand assets, and website-visual placeholders so the template and build contract travel with the skill. The deck includes a remote-care-general `Prove Remote Care for 90 Days` slide before the program/service slides; that proof-period frame is not CCM-only and must preserve readiness caveats. Its normal target remains a pharmacy, but explicit user authorization can apply the framework to a pharmacy operator, pharmaceutical company, healthcare organization, pharmacy-adjacent business, or other prospect. It preserves the verified business type, removes unsupported independent-pharmacy assumptions, and routes the applicable website, healthcare, pharmacy-operations, patient-support, provider-partnership, and remote-care story by prospect fit. Customer-facing slides use plain sales language and short material qualifications; the proposal research packet, calculation ledger, and evidence summary retain detailed sources, equations, assumptions, caveats, and fit limits.

`ToCreatePersonalizedPharmacyOnePageGrowthInsertSkill` creates a customer-facing stage-one insert around one evidence-backed pharmacy service-line mechanism. It uses the packaged `fairpath-one-page-insert-v1` template, requires an exact 33-slot content contract, rejects generic follow-up-lane concepts, and validates exact HTML, one-page PDF, and 2550x3300 preview artifacts before release.

`ToCreatePersonalizedPharmacyCurrentWebsiteFlyerSkill` is the lighter regular-prompt alternative for producing a human sales flyer from one pharmacy's current official website. It uses the packaged `fairpath-current-website-flyer-v1/flyer.html` template by default, embeds one clean unannotated website screenshot exactly once, and returns HTML, a one-page PDF, an exact 2550x3300 preview, evidence, structured content, and a production report for practical parent review. `ToOperatePersonalizedPharmacyCurrentWebsiteFlyerQueueSkill` provides bounded queue guidance for up to 10 one-lead workers, durable dispositions, and guarded CRM release.

Use this skill for work that sells, previews, proposes, or packages a website offer. Do not use it for real source-controlled client website implementation.
