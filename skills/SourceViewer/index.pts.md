# SourceViewer skill

`ToViewSourceFileInteractiveSite` is a thin launcher for the registered Source Viewer `file` screen. The Agent should resolve and inspect an exact path with file tools first, then pass the absolute path, presentation language (`text`, `javascript`, or `csharp`), optional one-based line, optional exact highlight text, and timeout. C# validates and serializes state. The browser component remains read-only and the existing server-side opened-handle authorization remains authoritative.
